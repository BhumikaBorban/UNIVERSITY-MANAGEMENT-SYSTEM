This is a University Management System built using Java Swing, AWT, and MySQL.
It allows management of student records, faculty details, courses, and academic activities.
The system features a user-friendly GUI and secure database connectivity.
Ideal for learning Java GUI development and backend integration.

🚀 Setup and Run Instructions
Open the project in NetBeans IDE.

Make sure JDK 8 or above is installed and configured.

Add the required JAR files (such as mysql-connector-java.jar,jcalendar-tz-1.3.3-4.jar,rs2xml.jar) to the project libraries.

Import the provided .sql file into MySQL to set up the database schema.

Edit the database connection details (username, password, DB name) in your Java code.

Clean and build the project, then run the main class to start the application.

📦 Dependencies
Java Development Kit (JDK) 8 or higher

NetBeans IDE

MySQL Server

mysql-connector-java.jar (JDBC driver)
